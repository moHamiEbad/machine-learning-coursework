
# Machine Learning Coursework

My theoretical problem sets and programming assignments for the **Machine Learning** course.

**University:** Tarbiat Modares University (TMU)  
**Instructor:** Dr. Mansoor Rezghi  
**Academic term:** 1405–1406, Semester 1 (4051)

## Repository structure

- [`theory/`](theory/) — Written problem sets, including LaTeX source and final PDFs.
- [`programming/`](programming/) — Programming assignments, experiments, and reproducible implementations.

## Development history

Each assignment is developed on its own Git branch and documented through a pull request. The commits show how the work evolves through initial attempts, revisions, validation, and final submission. Completed assignments are merged into `main`.

## Standalone projects

Programming assignments that grow into substantial independent projects may have dedicated repositories. Their assignment folders will link to those projects, keeping this repository as the central course archive.
